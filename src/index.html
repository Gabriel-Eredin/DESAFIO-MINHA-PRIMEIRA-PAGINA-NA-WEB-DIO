  • Entendendo a Comunicação Client-Server

  • (índice)

    O que são cliente e servidor e para que servem?

    A comunicação Client-Server, ou Cliente-Servidor, é um modelo muito utilizado na internet para permitir a troca de informações entre diferentes dispositivos e sistemas. Nesse modelo, o cliente é responsável por fazer uma solicitação, enquanto o servidor recebe essa solicitação, processa o que foi pedido e envia uma resposta. Quando acessamos um site pelo navegador, por exemplo, o navegador funciona como o cliente e solicita ao servidor os arquivos necessários para carregar aquela página.

    O cliente normalmente é a parte com a qual o usuário interage diretamente, como um navegador, aplicativo ou programa instalado no computador. Já o servidor é responsável por armazenar, processar ou fornecer informações e serviços para os clientes conectados a ele. Um servidor pode, por exemplo, armazenar os arquivos de um site, consultar um banco de dados, autenticar usuários ou processar informações enviadas por um formulário.

    Essa comunicação geralmente acontece através de uma rede utilizando protocolos específicos. Na web, um dos principais protocolos utilizados é o HTTP, ou sua versão segura, HTTPS. Quando digitamos o endereço de um site, o navegador envia uma requisição HTTP para o servidor responsável por aquele endereço. O servidor então analisa a requisição e devolve uma resposta contendo os dados solicitados, que podem incluir arquivos HTML, imagens, estilos CSS, scripts JavaScript ou outras informações.

    Esse modelo é importante porque permite separar responsabilidades. O computador do usuário não precisa armazenar todas as informações de um serviço, pois pode solicitar apenas aquilo que precisa ao servidor. Ao mesmo tempo, um mesmo servidor pode atender vários clientes diferentes, permitindo que diversas pessoas utilizem um site ou sistema através da internet.

  • Introdução ao HTML

  • (índice)

    O que é HTML?

    HTML, sigla para HyperText Markup Language, ou Linguagem de Marcação de Hipertexto, é a linguagem utilizada para criar e organizar a estrutura das páginas da web. Apesar de muitas vezes aparecer junto de linguagens de programação, o HTML não é considerado uma linguagem de programação, pois não trabalha diretamente com estruturas como condições, cálculos ou algoritmos. Sua principal função é definir o conteúdo e a estrutura de uma página.

    Na prática, o HTML funciona como uma espécie de estrutura base de um site. Através dele podemos informar ao navegador o que é um título, um parágrafo, uma imagem, um link, uma lista, um formulário e diversos outros elementos que fazem parte de uma página.

    Um documento HTML é interpretado pelo navegador. Quando o navegador recebe esse arquivo, ele identifica os elementos presentes no código e os transforma na página visualizada pelo usuário. Por exemplo, podemos utilizar uma determinada marcação para indicar que um texto deve ser considerado um título e outra para indicar que determinado conteúdo é um parágrafo.

    HTML também costuma trabalhar junto com outras tecnologias. O CSS é utilizado principalmente para controlar a aparência da página, como cores, tamanhos, fontes e posicionamento dos elementos. Já o JavaScript pode adicionar comportamentos e interatividade. Dessa forma, o HTML define principalmente o que existe na página e como seu conteúdo está estruturado.

  • Tags

  • (índice)

    Tags, as ferramentas do HTML

    As tags são marcações utilizadas pelo HTML para identificar e estruturar os diferentes tipos de conteúdo existentes em uma página. Elas permitem informar ao navegador qual é a função de cada elemento, indicando, por exemplo, se determinado conteúdo representa um título, parágrafo, link, imagem ou item de uma lista.

    A maioria das tags possui uma abertura e um fechamento. Um parágrafo, por exemplo, pode ser criado utilizando a tag <p> para iniciar o elemento e </p> para finalizá-lo. O conteúdo que estiver entre essas duas marcações será interpretado pelo navegador como um parágrafo.

    Existem também elementos que não precisam envolver um conteúdo de texto da mesma forma, como a tag <hr>, utilizada para representar uma separação temática entre partes de uma página. A maneira correta de utilizar cada tag depende do elemento que está sendo criado.

    Além da aparência apresentada pelo navegador, escolher corretamente as tags também ajuda a organizar semanticamente o documento. Isso facilita a leitura do código, melhora a acessibilidade da página e permite que navegadores e mecanismos de busca compreendam melhor a função de cada parte do conteúdo.

  • Atributos

  • (índice)

    Atributos, os detalhes que configuram

    Os atributos são informações adicionais que podem ser colocadas dentro das tags HTML para modificar ou complementar o comportamento de um elemento. Enquanto a tag determina qual é o elemento, o atributo pode fornecer características ou informações específicas sobre ele.

    Um exemplo comum acontece com a tag <a>, utilizada para criar links. Apenas informar que determinado elemento é um link não é suficiente, pois também precisamos indicar para onde ele deve levar. Para isso podemos utilizar o atributo href, como em:

    <a href="https://exemplo.com">Site</a>.

    Nesse caso, href informa qual endereço será aberto quando o usuário clicar no link.

    Os atributos são normalmente escritos dentro da tag de abertura e possuem um nome e um valor. Dependendo da tag, diferentes atributos podem ser utilizados. Alguns podem definir endereços, identificadores, classes, comportamentos ou outras informações necessárias para o funcionamento do elemento.

    Também existem atributos que podem ser utilizados em praticamente qualquer elemento HTML, como id e class. Eles são muito utilizados em conjunto com CSS e JavaScript para identificar elementos específicos da página ou agrupar elementos que possuem características semelhantes.

  • Exemplos de Tags

  • (índice)

    Segue uma lista com alguns exemplos de Tags que você vai ouvir falar e provavelmente usar:

      • <h1>: Define o título principal de uma página ou de uma seção importante do conteúdo. O HTML também possui títulos de <h2> até <h6>, formando diferentes níveis de hierarquia.

      • <p>: Cria um parágrafo de texto, sendo uma das tags mais utilizadas para organizar conteúdo escrito em uma página.

      • <mark>: Destaca uma parte do texto como se ela tivesse sido marcada com um marca-texto.

      • <small>: Representa informações secundárias ou textos com menor importância, normalmente exibidos em tamanho reduzido.

      • <i>: Indica um trecho de texto diferenciado do restante, normalmente apresentado em itálico pelo navegador.

      • <u>: Representa um trecho de texto com uma anotação diferente do conteúdo normal, sendo geralmente exibido sublinhado.

      • <strong>: Indica que determinado conteúdo possui grande importância ou relevância. Normalmente é exibido em negrito.

      • <ol>: Cria uma lista ordenada, geralmente apresentada com números ou outra forma de sequência.

      • <ul>: Cria uma lista não ordenada, normalmente apresentada utilizando marcadores.

      • <li>: Representa cada item existente dentro de uma lista criada com <ol> ou <ul>.

      • <a>: Cria um link que pode levar o usuário para outra página, arquivo, endereço da internet ou parte do próprio documento.

      • <hr>: Representa uma mudança ou separação temática entre diferentes partes de um conteúdo, normalmente exibida como uma linha horizontal.

      • <sub>: Exibe um texto em subscrito, ficando abaixo da linha normal do texto. É útil, por exemplo, em fórmulas químicas.

      • <sup>: Exibe um texto em sobrescrito, ficando acima da linha normal do texto. Pode ser utilizado em potências matemáticas.

      • <blockquote>: Representa uma citação mais extensa retirada de outra fonte, normalmente apresentada separada do restante do texto.

      • <font>: Era utilizada para modificar características como fonte, tamanho e cor de um texto. Atualmente é considerada obsoleta e essas alterações devem ser feitas utilizando CSS.

      • <del>: Indica que determinado conteúdo foi removido ou deixou de ser válido, normalmente sendo apresentado com o texto riscado.

      • <abbr>: Representa uma abreviação ou sigla e pode utilizar o atributo title para informar seu significado completo.

  • Exemplos de Atributos

  • (índice)

    Agora segue uma lista com alguns exemplos de Atributos que você vai ouvir falar e provavelmente usar:

      • href: Define o endereço de destino de um link criado com a tag <a>.

      • src: Define o caminho ou endereço de um recurso externo, como uma imagem, vídeo ou arquivo de script.

      • alt: Fornece um texto alternativo para imagens, importante para acessibilidade e para casos em que a imagem não pode ser carregada.

      • id: Define um identificador único para um elemento HTML, permitindo localizá-lo através de CSS, JavaScript ou links internos.

      • class: Define uma ou mais classes para um elemento, permitindo agrupá-lo com outros elementos e aplicar estilos ou comportamentos em conjunto.

      • style: Permite aplicar regras CSS diretamente em um elemento HTML.

      • title: Adiciona uma informação complementar ao elemento, normalmente exibida pelo navegador quando o cursor permanece sobre ele.

      • target: Define onde o conteúdo de um link será aberto, como na mesma página ou em uma nova aba.

      • type: Define o tipo ou comportamento de determinados elementos, como campos de formulário, botões e scripts.

      • value: Define o valor inicial ou atual de determinados elementos, principalmente campos de formulário e botões.

      • placeholder: Exibe um texto temporário dentro de um campo de entrada para indicar ao usuário qual informação deve ser inserida.

      • name: Define um nome para o elemento, sendo muito utilizado para identificar dados enviados através de formulários.

      • required: Indica que um campo deve ser obrigatoriamente preenchido antes que um formulário possa ser enviado.

      • disabled: Desativa um elemento, impedindo que o usuário interaja com ele.

      • width: Define a largura de determinados elementos, como imagens e vídeos.

      • height: Define a altura de determinados elementos, como imagens e vídeos.

  • Observações Sobre Tags e Atributos

  • (índice)

    Tags, elementos, atributos e a importância de saber diferenciá-los.

    É importante diferenciar tag, elemento e atributo. A tag é a marcação escrita entre os sinais < e >, como <h1>, <p> ou <a>. Já o elemento HTML é a estrutura completa formada pela tag de abertura, seu conteúdo e, quando necessário, a tag de fechamento. Por exemplo, em <p>Texto</p>, <p> e </p> são as tags, enquanto todo o conjunto forma o elemento.

    Os atributos adicionam informações ou configurações extras aos elementos e normalmente são escritos dentro da tag de abertura. Alguns atributos são globais e podem ser utilizados em praticamente qualquer elemento HTML, como id, class, style e title. Outros possuem funções específicas e só fazem sentido em determinados elementos, como href em links, src em recursos externos e placeholder em campos de formulário.

    Por isso, apesar de tags e atributos trabalharem juntos, eles possuem funções diferentes: as tags ajudam a definir a estrutura e o significado do conteúdo, enquanto os atributos complementam ou configuram o comportamento dos elementos.
