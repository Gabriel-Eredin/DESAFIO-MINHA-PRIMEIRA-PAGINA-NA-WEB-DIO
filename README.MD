# Criar Uma Página Web Utilizando as Tags Aprendidas


Este projeto é um desafio da Formação HTML Web Developer da DIO. O objetivo é criar uma página web utilizando os conceitos de HTML aprendidos até o momento, simulando um blog com uma publicação explicando, com minhas próprias palavras, alguns dos principais fundamentos estudados durante o curso até agora.

A publicação aborda conceitos como comunicação Client-Server, introdução ao HTML, tags, atributos, elementos HTML e exemplos de algumas das tags e atributos mais utilizados.

Além do conteúdo escrito, o site também utiliza diferentes recursos do HTML para organizar a página, criar uma navegação interna entre as seções e apresentar referências utilizadas durante os estudos.

## O que eu usei:

- Estrutura básica de um documento HTML
- Tags de títulos como `<h1>`, `<h2>`, `<h3>` e `<h4>`
- Parágrafos com `<p>`
- Listas utilizando `<ul>` e `<li>`
- Links utilizando `<a>`
- Atributos como `href`, `id`, `title`, `target`, `style`, `src` e `alt`
- Links internos utilizando `id` e `href`
- Links externos
- Imagens utilizando `<img>`
- Tags de formatação como `<strong>`, `<i>` e `<u>`
- Separação de conteúdo utilizando `<hr>`
- Citações utilizando `<blockquote>`
- Entidades HTML como `&lt;` e `&gt;` para exibir tags como texto
- Configurações básicas do documento como `DOCTYPE`, `lang`, `charset` e `viewport`

## Conteúdo da publicação:

O blog foi dividido em diferentes partes para apresentar de forma simples alguns dos conceitos que aprendi até agora:

- Comunicação Client-Server
- Introdução ao HTML
- Tags
- Atributos
- Exemplos de tags
- Exemplos de atributos
- Diferença entre tags, elementos e atributos
- Referências e fontes utilizadas durante os estudos

## Explicação do meu projeto:

Para este desafio, decidi fazer a página como se fosse uma publicação de um blog voltado para quem está começando a estudar desenvolvimento web.

Tentei criar uma página que tivesse uma estrutura e uma utilidade real. Todo o conteúdo foi escrito com base no que aprendi até agora durante a Formação HTML Web Developer, explicando os conceitos com minhas próprias palavras e adicionando alguns exemplos para facilitar a compreensão.

Contém um índice no início da página utilizando links internos como pedido pelo professor. Cada tópico possui um `id`, permitindo que os links do índice levem diretamente para a parte correspondente da publicação. Também adicionei links para retornar ao índice durante a leitura.

Utilizei listas para organizar tanto o índice quanto os exemplos de tags e atributos, além de diferentes níveis de títulos para criar uma hierarquia no conteúdo. Também utilizei atributos como `style`, `href`, `id`, `title`, `target`, entre outros ao longo da página.

Como o próprio conteúdo fala sobre HTML, também precisei utilizar entidades como `&lt;` e `&gt;` para conseguir mostrar tags como `<p>`, `<h1>` e `<a>` na publicação sem que o navegador interpretasse essas demonstrações como elementos reais da página.

Por fim, adicionei uma seção de referências com materiais da DIO e outras fontes utilizadas durante meus estudos, além dos meus links para GitHub e LinkedIn.

Ainda não entrei na parte de CSS da formação, então algumas decisões visuais e de espaçamento foram feitas utilizando apenas os recursos de HTML que conheço até o momento. A ideia é que este projeto também sirva como um registro do meu progresso para que futuramente eu consiga comparar com páginas mais completas conforme avançar nos estudos.
